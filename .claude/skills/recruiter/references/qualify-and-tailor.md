# Qualify a lead & tailor resume/profile

## Workflow 2: Qualify a lead (paste a post → "worth it?")

Score 0–2 on each, then give a verdict: **Go / Go as contract pitch / Skip**.

| Factor | 2 | 1 | 0 |
|---|---|---|---|
| Stack fit | Fabric/Power BI/dbt core | adjacent (Synapse, Snowflake + PBI) | different stack |
| Engagement | consulting/contract/fixed | perm but open to contract | perm only, on-site |
| Location/hours | remote, EU/UK/ME hours | remote, US East | requires residency/visa or APAC hours |
| Budget/rate | ≥ his rate | near it | far below |
| Speed | starts ≤ 2 wk, clear scope | vague timing | long process, multiple panels |
| Proof match | 300+ users / migration / CI/CD story fits directly | partial | none |

Also flag red flags: unpaid "test projects" larger than 2 hours, payment outside the platform before a contract, vague scope with a fixed low budget, requests for personal documents before a call, crypto payment.

## Workflow 3: Tailor the resume / profile to a posting

Input: the posting plus his current resume (ask for it if it isn't in the conversation; use the baseline profile only as a fallback and say so).

Output, in this order:
1. **Fit snapshot**: one line, e.g. "Strong fit (9/12); gap: Databricks."
2. **Match table**: requirement → his true evidence → strength (✔ strong / ~ partial / ✘ gap).
3. **Keywords to mirror**: the exact terms from the posting that should appear in the resume. ATS and recruiters match literally ("Power BI" and "PowerBI", "CI/CD" and "deployment pipelines").
4. **Rewritten pieces**, ready to paste:
   - Headline / title line matching their role title (if truthful).
   - 3-line summary aimed at this role.
   - The 4–6 most relevant bullets, reordered and reworded as *action + scope + result*, using his real numbers.
   - Skills line ordered by their priorities.
5. **Gaps & honest framing**: what to say if asked about each gap, plus one quick thing he could do (a lab, an Applied Skills credential, a demo) to close it.
6. **Cover note or proposal opener** (see Workflow 4).

Resume conventions: one page for contracts (two max for perm), reverse chronological, numbers in the first half of each bullet, no photo for UK/US perm roles (a photo is fine on marketplace profiles), PDF named `Kirill_Vosk_<Role>_<Company>.pdf`, certifications near the top with the Microsoft Learn transcript link.

For **platform profiles** (Upwork, Contra, LinkedIn, Toptal, etc.): give field-by-field copy within the platform's limits. Headline = specialism + cert + outcome, not job title. Portfolio items = problem → what he built → result, with visuals on sample data.
