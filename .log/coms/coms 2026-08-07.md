- **The hover fill is a `::before` wipe, not a background transition** — `translateX(-105%) → 0` with a constant `skewX(-10deg)`. Negative angle on purpose: CSS y grows downward, so a negative skew pushes the top edge right of the bottom, which is the direction an italic face leans. - **The fill bleeds 12px past both ends in fixed px, not %** — a 10deg lean across a 40px height displaces ~7px, so a flush-width fill leaves a triangular gap at one corner. The gap is set by the height (identical on every button), not the width (which differs), so a percentage would be the wrong unit. #decision
- **`isolation: isolate` + `z-index: -1` instead of a wrapper span** — puts the fill above the button's own background but below the label, so no extra markup and no z-index on the text.
