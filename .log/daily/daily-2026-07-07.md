## Bug fixed — popup clipped in header
- **Symptom:** the Message popup appeared trimmed inside the 56px header instead of centered over the page.
- **Root cause:** the sticky header uses `backdrop-blur`. An element with `filter`/`backdrop-filter`/`transform`/`will-change` becomes the **containing block for `position:fixed` descendants** — so `fixed inset-0` resolved against the header box, not the viewport. `items-center` was cosmetic and couldn't fix it.
- **Fix:** `createPortal` the modal to `document.body`, escaping the containing block. Now covers the true viewport.

## Decisions / notes
- **Decisions:** reused the existing `ContactForm` (+ Server Action) inside the popup rather than a new form; used the `--primary` token (`#4F46E5`) for the italic accent words and `--foreground` for the dark CTA (no new colors); footer change is intentionally site-wide.
- **Guardrail worth remembering:** never render a `position:fixed` overlay inside an ancestor with `filter`/`backdrop-filter`/`transform`/`will-change` — portal it to `body`.
