## Two items that were described wrongly

### `metadataBase` — reopened, root-caused, fixed ✅
I closed this at kickoff on a read of `[locale]/layout.tsx:44` and **was wrong**; the build still
warned. It also was not "two routes", as the warning count suggested.

Root cause: `src/app/opengraph-image.tsx` is attached to the **root** segment, which had no layout
and therefore no `metadataBase`. Next resolves metadata top-down, so the locale layout's base always
arrived too late. The image resolves for *every* prerendered route — 36 hits — and `warnOnce`
collapsed that to one line per static-generation worker process. Two workers, two warnings.

Fix: a passthrough `src/app/layout.tsx` that supplies `metadataBase` and nothing else; removed from
the locale layout so there is one source. Warnings 2 → 0. With `NEXT_PUBLIC_SITE_URL=https://vosk.dev`,
canonical, `og:url`, sitemap `<loc>` and the feed self-link all emit the production domain.

### The 404 — there wasn't one ✅
The backlog said "no localized `[locale]/not-found.tsx`". The truth was worse: **that file had never
rendered in production.** `dynamicParams = false` 404s at the routing layer *before* the segment tree
is entered, so the boundary never mounts. Probed live against a production build — all four URL
shapes returned Next's built-in "This page could not be found."

It was also not free: the dead boundary is serialized into every route's RSC payload, which is why
English "Page not found" strings were sitting inside the Russian homepage HTML.

**First attempt, rejected:** reading a proxy-stamped `x-locale` header inside the segment
`not-found.tsx`. It produced correct output — and flipped every `[locale]` route from `●` SSG to
`ƒ` dynamic, because one dynamic API taints the whole loader tree. Caught by diffing build output
against a reverted copy, not by reading. Reverted.

**Adopted (user-approved):** `app/global-not-found.tsx` behind `experimental.globalNotFound`. It
compiles into the separate `/_not-found` entry, so `headers()` there makes only that one route
dynamic. Fonts extracted to `lib/fonts.ts` since the file bypasses the layout and needs its own
`<html>`/`<body>`. The `dict.notFound` keys — present in both catalogues and referenced nowhere since
they were written — are finally load-bearing.

## Session 2 — syndication (Goal D) ✅ shipped

Captured at 08-01 kickoff as a big, later task. Implemented the same day.

### Research reversed the plan's own table

The plan carried a per-platform friction table flagged **"re-verify, this moves."** It did.

- **X** — the plan's "~$100/mo Basic, be willing to drop it" is obsolete. The free tier is gone;
  pay-per-use is the 2026 default for new developers at **$0.015/post, $0.20 when the post contains
  a link** — and every syndication post contains a link. A few dollars a year at this cadence. The
  expected blocker evaporated.
- **LinkedIn** — the plan had it **backwards**. It assumed a Company Page was the easier path. In
  fact personal-profile posting is the *self-serve* one (add **Share on LinkedIn** in the Developer
  Portal → `w_member_social`, no app review), while the Company Page runs through the Community
  Management API, which is *"not available to individuals at all"* and gated behind a registered
  legal entity plus a two-tier review. The expected easy win was the closed door.
- **Dev.to** — confirmed exactly as described. Free, `api-key` header, `canonical_url` supported.

**User chose Dev.to + LinkedIn personal; X dropped** — explicitly *not* on cost, but on audience fit
and on every extra platform being another credential to rotate and another way to post something
wrong under the author's name. `ADR-0004` records all eight open decisions, resolved.

### Copy model changed mid-build, at user request

Not a full-text cross-post — an **auto-generated teaser with a CTA** that converts a LinkedIn/Dev.to
reader into a click through to vosk.dev. Title, the hand-written `description`, up to three opening
paragraphs, then the link.

Generated **deterministically** (`lib/syndication/summary.ts`), no LLM. Stated at the time as an
assumption rather than decided silently, and the reasoning is load-bearing: the CI approval gate is
only meaningful if the dry run and the publish emit *identical* text. A non-deterministic generator
in a public, irreversible posting path would make the preview a guess.

### What was built

`lib/syndication/` — `types` · `items` · `summary` · `manifest` · `devto` · `linkedin` · `run`.
One adapter per platform behind a four-method interface, the same boundary instinct that made the
Preset → Superset reversal cost ~60 lines. Plus `scripts/syndicate.mts` (`pnpm syndicate`, dry-run
by default), a committed `syndication.json` as the state store, `.github/workflows/syndicate.yml`,
`docs/04-syndication.md`, and `ADR-0004`.

**State is git.** The repo is deliberately DB-free, so "what has been posted where" is a committed
JSON file keyed per item *per platform*. That choice is what forces the runner into GitHub Actions —
a Vercel function cannot commit back to the repo.

**Five layers stop a bad post:** `--publish` is opt-in; a never-run manifest refuses to publish >1
item without `--backfill`; the CI publish job waits behind a protected environment while a human
reads the drafted copy; `draft: true` showcases are never syndicated; and the runner refuses to
start unless `NEXT_PUBLIC_SITE_URL` is a public `https://` origin.

  and JSX-stripping logic is line-oriented, and the MDX is read straight off disk — CRLF on this
  Windows checkout. `\n{2,}` never matches `\r\n\r\n`, and multiline `$` sits *after* the `\r`. An
  entire article collapsed into one block; `<WorkflowDiagram />` and `## The problem` leaked into
  the teaser. Normalised at the seam, pinned by tests on both paths. #bug
- **The placeholder showcase was queued to post.** `work/retail-sales` — whose copy literally reads

  LinkedIn. Spotting that in a dry run is not a control, so `Showcase` gained a `draft` flag

- **The first Dev.to draft was a run-on blob**, welding unrelated paragraphs together including
  lead-ins like *"Here's the sample we'll work with:"* whose code block had just been stripped. The
  excerpt now stops at that boundary.

Two of these three were only visible because the dry run prints the **full body**, not a character
count. That was a deliberate choice and it paid for itself immediately.
