## Findings

1. #decision **The tools run on the server**, not in the browser (the 11-05 plan): one request per question, no
   forged results, nothing to download beside the Power BI iframe. ADR-0005.
2. #decision **No `temperature`, effort low.** Haiku 5.5 rejects a non-default temperature (the 11-05 plan had 0.2).
   Thinking stays adaptive; `max_tokens` 1,024 leaves room for it.
3. #decision **"Any question" = free text in, off-topic declined in one sentence.** Without the decline, the route is a
   free public LLM on the owner's key. Offered to loosen to general BI questions.
4. **Prompt rules from the smoke test:**
   - the model described its tools ("the trend tool only returned…") and said "the overview view";
   - two rules fixed it: never mention tools or views; say the scope in a few words;
   - plain text only, because the panel does not render Markdown.
5. **Cost and speed:**
   - $0.0004–0.0006 per answered question; an off-topic decline costs $0.00006;
   - ≈ 4 s warm, ≈ 8 s on a cold instance (the engine reads the base artifacts once);
   - production's first real question took 5.0 s.
