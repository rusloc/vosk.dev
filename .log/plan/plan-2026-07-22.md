## New idea — ASCII code-face (home lower-right)  ·  *blocked on photo*

Replace the `CodeTyper` code block with a **typed-in ASCII portrait** that slowly reveals a face.
- **Spec (locked):** **sequential** reveal, **loop** (reveal → hold → clear → retype), **purely
  decorative** — no hover-unblur, no click-to-popup clear view; reduced-motion → static full art.
- **Approach:** reuse the existing typing engine in `code-typer.tsx`; **batch the reveal** (the art is
  thousands of chars — per-char at 45ms would take minutes); delete the `.hit` button + `CodePopup`.
  Dropping all interaction removes the z-index / `pointer-events` wrinkle a hover target would need.
- **Real cost = the asset**, not the code: generate the ASCII from the portrait, then tune columns,
  char ramp, contrast, and per-breakpoint font-size so the face reads at corner size — eyeballed on
  the **preview**, and approved as a still **before** wiring the animation.
- **Blocked:** source portrait. User to save it to `article-src/service-page/portrait.png`
  (front-facing, high-contrast, plain background — already provided a good one). Then: generate still →
  approve → wire the loop. Python 3.10 + PIL 9.5 confirmed available locally for the conversion.
