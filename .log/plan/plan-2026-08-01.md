**Code items, no user input needed:**

1. **Bug: empty-string `RESEND_API_KEY` 500s the contact form.** `getContactConfig()` sits outside
   the try/catch (`contact/actions.ts:67`), so a present-but-empty env var throws a ZodError out of
   the Server Action — bypassing the graceful fallback written for exactly that case. _Highest-value
   unblocked item on this list._
2. **Bug: no `og:image` on any non-post page.** `buildMetadata` sets `openGraph` wholesale, so Next
   replaces the root segment's card. `/en/services` confirmed to have none. Every service, work and
   index page shares with a blank preview. Fix is likely `images` in `buildMetadata`'s `openGraph`.
3. **Bug: Zod's built-in messages leak English into the Russian form** — `email.max(200)`,
   `subject.max(150)`, and the missing-`message` type error carry no `t.*` string.
4. **i18n Phase 3, remainder** — blog MDX is single-language, so `/ru/blog/*` renders English bodies.
   `content.ts` has no locale dimension. This is a **design decision** (per-locale files? a `.ru.mdx`
   suffix? frontmatter keyed by locale?), not a translation task — decide the shape before writing prose.
5. **`three-numbers` 404** — decide redirect vs leave.
6. **iframe `sandbox` hardening** on `/work/[slug]`.
7. **Turnstile** — adopt or explicitly drop; honeypot + rate limit are in place and now tested.
8. **Rate-limit durability** — in-memory `Map` in two places. Now also known to grow unbounded (one
   entry per IP, forever). Harmless on serverless; extract to `lib/rate-limit.ts` if a third caller
   appears.
9. **Test coverage gaps worth closing next** — `escapeHtml` (`lib/contact-email.ts`) is the only
   guard between visitor input and email HTML and is untested; `content.ts`'s "fail the build loudly"
   guarantee is unverified. The harness now exists, so both are cheap.
