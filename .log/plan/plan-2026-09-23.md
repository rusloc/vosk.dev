### T.5 Make the engine free — and outage-proof by construction _(new 14:40)_

**Costed from evidence today: Anthropic is the *only* paid thing in the loop.** Himalayas, Telegram,
`pg_cron` and Edge Functions are all $0. Measured inflow **41.4 postings/day** (14-day avg), ~1,150
tokens of posting text + ~985 fixed (system prompt + tool schema), ~200 out. At Haiku 4.5 **$1 / $5
per MTok** (checked against the current table, not recalled) that is **≈ $0.0032/posting ≈ $4/month.**
The outage is a dry $4 balance, not a cost problem.

⚠️ **The finding underneath it: the engine pays Haiku to re-derive fields the source already
publishes.** Himalayas' payload carries `employmentType` and `locationRestrictions`, and
`fetch-himalayas` already runs a BI keyword regex to decide what to store. So `engagement_fit` (25)
+ `remote_fit` (20) + `stack_fit` (15) = **60 of 100 points are computable in TypeScript with no API
call**, and translation is dead weight on an English-language board. Only the two-sentence `summary`
genuinely wants a model.

Ranked, effort against benefit:

1. **Batch API — −50%, zero quality loss, smallest diff.** Nothing here is latency-sensitive; it
   feeds a *daily digest*.
2. **Rules-first score, model only for survivors' summaries** — _recommended_. Cuts call volume and
   shrinks output ~3×, and makes the score **free to re-run when §0 settles** instead of re-billing
   900 postings.
3. **Fully rules-based = $0 forever**, no key to expire. Backtestable offline against the 932 leads
   already scored — a free experiment that needs no credits and can be run *today*.
4. Prompt caching is the obvious-looking lever that probably will not fire: the ~985-token fixed
   prefix is likely under Haiku's minimum cacheable prefix, and the 15-min cadence outlives the
   5-min default TTL. **Verify before counting on it.**

⚠️ Two constraints on any of them: **T.1 step 4(a) must be fixed regardless** — a cheaper engine
that fails invisibly is the same engine. And **rules hard-code a definition of "lead"**, so if §0 is
still open the table must be written as data, not as `if` statements.
